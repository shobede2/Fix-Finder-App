# Fix Finder 

Fix Finder is an Android mobile application designed to help users find and connect with service providers for different repair and maintenance needs.

The application provides a simple interface where users can access the available services, manage their account, and interact with the application's features from their mobile device.

##  Features

* User sign-in/authentication
* User-friendly mobile interface
* Service provider/repair service discovery
* Settings menu
* REST API integration
* Navigation between application screens
* Responsive Android user interface
* Error handling and validation

## Technologies Used

* **Android Studio**
* **Kotlin**
* **Android SDK**
* **XML Layouts**
* **REST API**
* **Git & GitHub**
* **Gradle**

##  Requirements

To run Fix Finder, you will need:

* Android Studio
* Android SDK
* A physical Android device or Android Emulator
* Internet connection for features that use the REST API

##  Authentication

Fix Finder includes a sign-in feature that allows users to access the application.

User authentication and validation are handled within the application according to the implemented authentication functionality.

## REST API

Fix Finder uses a REST API to communicate with external/backend services.

The API is used to send and retrieve application data through HTTP requests.

The application handles API responses and displays the relevant information within the mobile interface.

##  Settings

The application includes a Settings section where users can access available application preferences and options.
